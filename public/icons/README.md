# Icons Directory

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows icon)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Icon Creation

For testing, you can:

1. Use an online generator like https://favicon.io/
2. Create simple PNG images with a trading/chart icon
3. Use blue gradient colors (#0ea5e9 to #06b6d4)
4. Export at the required sizes

See [CREATE_ICONS.md](../../CREATE_ICONS.md) for detailed instructions.

## Temporary Solution

The extension will work without icons - Chrome will show a default placeholder. You can add proper icons later for a polished look.
